# Calculator

一个基于 Android 的简易计算器应用，支持加、减、乘、除四则运算。

## 开发环境

- Android Studio 2020.3.1 Patch 4
- 语言：Java
- 最低 SDK：API 29 (Android 10.0)
- 目标 SDK：API 30

## 功能

- 输入两个数字
- 点击按钮执行加(+)、减(-)、乘(×)、除(÷)运算
- 除以零时弹出提示
- 显示计算结果

## 使用方式

1. 克隆仓库：`git clone https://github.com/Andy0613/Calculator.git`
2. 用 Android Studio 打开项目
3. 连接模拟器或真机，点击 Run 运行
